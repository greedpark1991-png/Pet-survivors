# 멍냥 서바이버즈 — Phaser 웹게임 v1.18

작은 도트 강아지·고양이가 반려동물에게 위험한 음식 몬스터 떼를 버티는 탑다운 서바이버 로그라이트입니다. 혼자 플레이하거나 같은 Render 링크에서 2인 온라인 협동으로 플레이할 수 있습니다.

## v1.18 — Boss Evolution & Run Variety

- 기본 런을 15분 목표 구조로 정리: 3분 포도 → 6분 초콜릿 → 9분 양파 → 12분 커피 → 15분 자일리톨 껌
- 기존 3분 포위 이벤트는 첫 포도와 겹치지 않도록 2분 30초로 앞당겨 이벤트 자체는 유지
- TRUE BOSS 5종 모두 Phase 1 / Phase 2(65%) / Final(20%)의 외형·패턴 변화 + Final 필살기 1회
- 자일리톨 처치 후 `산책 완료!` 화면, 다시 시작 / 로비 / 계속 산책하기(Endless) 지원
- TRUE BOSS 공통 r25 hurtbox를 보스별 r27~31 개별 hurtbox로 확장하고 F2 debug에 표시
- 산책줄을 캐릭터별 목/등 뒤 anchor + 휘어진 리드줄/손잡이 그래픽으로 변경, Lv.3~5 두 줄 길이 동기화
- 발톱 슥삭을 진짜 3줄 claw mark로 변경하고 사거리 62 → 80 → 88 → 102 → 128px 성장, Lv.5 중거리 8방향 + 발톱 마무리
- 초콜릿 장판을 340ms 준비 → 650ms 착탄 예고 → 500ms 포물선 투사 → 착지 장판 순서로 연결
- 포도송이 분열탄은 최소 210px 이동 / 기본 780ms 뒤 분열
- TRUE BOSS 전환 시 살아 있는 적 + 바닥 XP를 100% 보존하고, 기존 상자/간식/자석도 삭제하지 않음
- 신규 커피 보스: 빠른 조준 / 1회 방향전환 / 커피 연사 / 카페인 폭주
- 신규 자일리톨 보스: bounce / 끈적 장판 / 공간 제어 / 풍선껌 대폭발
- 멍배송 보급상자: 45~75초 랜덤 낙하, 1초 예고, 간식/버프/자석/수상한 약/스킬 +1/병맛 보너스
- 2인에서 boss phase, 착탄 telegraph, delivery warning, Final 필살기 경고를 기존 snapshot/compact extras로 동기화
- v1.17 스킬 성장, v1.16.2 honest collision, pendingTrueBoss, 보상 보호, 부활, Host-authoritative, interpolation/local prediction/volatile 전송 유지

세부 표는 `V1.18_BOSS_PHASES.md`, `V1.18_SKILL_FIXES.md`, `V1.18_DELIVERY.md`, `V1.18_CHANGELOG.md`, 검증 결과는 `V1.18_TEST_REPORT.md`를 참고하세요.


## v1.16.2 COMBAT FEEL / COLLISION HOTFIX

v1.16.2는 전투 밸런스·성장·적 HP·보스 HP·증강 수치를 변경하지 않고, 실제 플레이에서 불쾌하게 느껴지던 **피격 판정 / 포도 TRUE BOSS 돌진 / 전투 배경 마감**을 집중 수정한 핫픽스입니다.

### 플레이어 / 적 탄환 판정

- v1.16.1의 플레이어 사각형 판정을 몸통 중심 원형 판정으로 교체했습니다.
  - 찌개: radius 7, 원본 64×64 기준 중심 (31,47)
  - 만두: radius 7, 중심 (31,47)
  - 감자: radius 6, 중심 (33,50)
  - 구찌: radius 7, 중심 (31,49)
- 귀 / 머리 외곽 / 구찌 꼬리 / 털 끝은 실제 피격 중심에서 제외됩니다.
- 적 탄환은 보이는 외곽선보다 충돌 코어를 작게 사용합니다.
  - 일반/정예탄: visual r5 / hit r3.5
  - 일반 보스탄: visual r7 / hit r5.0
  - TRUE BOSS탄: visual r8 / hit r5.5
- 탄환과 플레이어 모두 Phaser Arcade의 circle body를 사용하므로 원형 탄막에서 사각 AABB 모서리에 맞는 현상을 줄였습니다.
- 개발 검사용 `F2` hitbox debug를 추가했습니다. 기본 OFF이며 일반 UI에는 노출되지 않습니다.

### 포도 TRUE BOSS 돌진

- 기존 220×14 화살촉 형태 `rushWarning`을 제거했습니다.
- 얇은 반투명 점선 바닥 텔레그래프 `rushLine`만 남기고, 공격을 보스 몸짓으로 읽을 수 있게 했습니다.
- 준비 중 포도가 약 6px 뒤로 힘을 모으고 2~3회 작게 좌우로 떨리며 마지막 순간 짧게 밝아집니다.
- 준비 시작 시 플레이어 위치를 잠그고, 돌진 중에는 방향을 다시 추적하지 않습니다.
- Phase 1은 잠근 목표를 약 52px, Phase 2는 약 60px 지나치는 지점을 목표로 합니다.
- 최대 돌진 거리 900px, 실제 이동시간 220~280ms, 기준 속도 1650px/s로 짧은 대쉬가 아니라 화면을 가로지르는 공격처럼 보이게 했습니다.
- 시작 먼지 / 90ms 간격의 짧은 잔상 / 종료 충격파를 소량만 사용합니다.
- 종료 후 380ms 명시적 recovery를 두고 짧은 딜타임을 만듭니다.
- 포도 돌진 재사용 간격은 약 6.8~9.2초이며 Phase 2 패턴이 이 제한을 무시하고 돌진을 연속 강제하지 못하게 했습니다.
- 돌진 종료 후 기존의 작은 원형탄 후속 공격은 유지됩니다.

### 전투 화면 미세 폴리싱

- v1.16.1의 연속 산책길 구조는 유지하되 길 폭과 중앙 광장을 한 번 더 줄였습니다.
- 길/잔디 경계 대비를 낮추고 3단계 흙색 레이어 + 낮은 알파의 마모/잔디 침범 픽셀을 사용합니다.
- 중앙 광장은 더 작은 저대비 팔각형으로 조정하고 발바닥 문양은 유지했습니다.
- 벤치 / 가로등 / 표지판은 같은 외곽선·제한 팔레트·바닥 그림자 규칙으로 맞췄습니다.
- 배경 GameObject 수나 물리 충돌은 늘리지 않았습니다.
- 우하단 사운드 버튼은 기존 safe area / 팝업 구조를 유지하면서 outline, hover, `SOUND` tooltip을 정리했습니다.

## v1.16 UI / 그래픽 리마스터

v1.16은 v1.15의 전투 밸런스와 네트워크 구조를 유지한 채 **로비·전투 HUD·공원 배경·캐릭터 표현·증강 카드·ESC 빌드 화면·보스 UI·사운드 UI**를 리마스터한 비주얼 패치입니다. 게임 로직 수치와 핵심 전투 시스템은 임의로 변경하지 않았습니다.

- 로비: 웹 설정창 느낌을 줄이고 큰 캐릭터 프리뷰 + 명확한 시작 버튼 중심의 게임 타이틀 화면으로 재구성
- 전투 HUD: 좌상단 HP/XP를 슬림화하고 우상단 시간/WAVE/KILL의 우선순위를 정리
- 빌드 HUD: 장문 텍스트 대신 작은 아이콘 슬롯 + Lv 표시, 상세정보는 ESC 화면에서 확인
- 공원 배경: 고정 seed 기반 잔디 톤 변화, 산책길, 중앙 광장, 연못, 꽃밭, 놀이터, 벤치, 울타리, 나무, 가로등, 표지판 추가
- 캐릭터: 렌더링만 약 8~11% 확대하고 기존 피격판정은 유지, 바닥 그림자/로컬·파트너 표시/피격·회복·레벨업·무적 피드백 추가
- 증강 카드: 큰 아이콘 → 이름 → 핵심효과 → 상세설명 → 종류 태그의 정보 계층으로 재정리, `data-type`/`data-rarity` 확장 포인트 추가
- ESC: 현재 캐릭터/특성, 핵심 스탯, 기본 강화, 특별·전용/Lv.10/보물 스킬을 구역별로 정리
- 사운드: 상시 슬라이더를 작은 ♪ 버튼 팝업으로 변경, 기존 localStorage 저장 유지
- 보스: 일반 보스와 TRUE BOSS HP바 위계를 분리하고 약 1.45초의 짧은 TRUE BOSS 경고 UI 추가
- 픽셀 렌더링: Phaser `pixelArt`, `antialias:false`, `roundPixels:true`와 CSS `image-rendering:pixelated` 유지
- 성능: 배경 장식은 물리 충돌 없는 Phaser GameObject 약 480개 수준으로 제한하고 고정 seed를 사용

## v1.15 기본 회복 루트

레벨업에서 체력 카드만 강제로 고르는 상황을 줄이기 위해 필드 회복 루트를 추가했습니다. 기존 최대 HP 강화와 마도사의 주스 상자는 그대로 유지됩니다.

- 간식: 먹은 플레이어 최대 HP의 20% 회복, 초과 회복 없음
- 일반몹: 간식 드롭 없음
- 정예: 처치 시 10% 확률로 간식 1개
- 일반 보스: 처치 보상에 간식 1개 확정
- TRUE BOSS: 처치 시 간식 2개 확정
- 모든 레벨업: 살아 있는 플레이어 최대 HP의 3% 회복
- 2인: 간식을 실제로 먹은 플레이어만 회복, DOWN 플레이어에게는 적용되지 않음

마도사의 주스 상자는 회복 특화 빌드 역할을 유지합니다. 개이득 다발탄의 첫 적중은 정상 회복하고 같은 짧은 연속탄 묶음의 후속 적중은 감소 효율을 적용하는 v1.14 안전장치도 유지됩니다.

후반 난이도는 HP/속도 폭증보다 적 수, 고속 적, 정예 비율, 정예 탄환, 변이, 혼합 습격, 보스 패턴으로 올립니다.

## 정예 변이

5분 이후부터 정예에게 한 가지 변이가 붙을 수 있습니다. 한 정예에게 여러 변이가 동시에 붙지는 않습니다.

- 신속: HP는 낮지만 빠르고 2연 탄환 사용
- 중장갑: 느리지만 HP/접촉 피해가 높음
- 분열: 죽을 때 약한 자식 몬스터 3마리 생성
- 지원: 주변 일반몹 이동속도를 소폭 강화하고 3발 지원 사격

변이 정예 위에 전용 이름/아이콘이 표시됩니다.

### v1.15 일반 보스 / TRUE BOSS 충돌 방지

TRUE BOSS 조건이 충족되어도 살아 있는 일반 보스를 즉시 삭제하지 않습니다.

- `pendingTrueBoss` 예약 상태로 전환
- 일반 보스가 살아 있으면 신규 일반몹/정예/이벤트 스폰 중지
- 약 24초 동안 현재 일반 보스를 마무리할 기회 제공
- 그 안에 처치하면 기존 보상 + 간식이 정상 드롭
- 24초를 넘기면 일반 보스를 정리하되 자석/보물상자 중 1개 + 간식 1개 보장
- 일반 보스 스폰 이후 TRUE BOSS 실제 시작까지 최소 약 60초 간격 확보
- TRUE BOSS 직후 60초 이내에 예정된 일반 보스는 해당 회차만 건너뛰어 보스 이벤트 중첩 방지
- TRUE BOSS 전장 정리 시 살아 있던 일반몹/정예의 원래 XP 총량 중 50%를 팀 XP로 지급
- 이미 필드에 떨어진 경험치 보석, 자석, 보물상자, 간식은 삭제하지 않음

따라서 TRUE BOSS 타이머 때문에 진행 중이던 일반 보스 전투와 성장 보상이 통째로 무효화되지 않습니다.

## TRUE BOSS

WAVE 35 / 70 / 105...에서 TRUE BOSS 이벤트가 예약됩니다. 일반 보스가 겹쳐 있지 않으면 기존처럼 빠르게 전환하고, 일반 보스가 살아 있으면 위의 pending 시스템으로 먼저 마무리 시간을 줍니다.

실제 TRUE BOSS 전환 시:

1. 일반 스폰 중단
2. 남은 일반몹/정예 정리 + 정리 XP 50% 지급
3. 기존 적 탄환 정리
4. 약 1.25초 경고
5. 보스 이름 표시
6. 전용 탄막전 시작

보스는 거대 포도 → 거대 초콜릿 → 거대 양파 순서로 반복되며 HP 50% 이하에서 2 PHASE에 진입합니다. v1.15에서는 단일 공격 분기 대신 패턴 메타데이터(`id / phase / weight / cooldown / minDistance / condition / execute`)를 사용하고 최근 2개 패턴을 우선 회피해 같은 공격이 연속으로 몰리는 현상을 줄였습니다.

### 거대 포도

Phase 1:
- 회전 원형탄: 이동하는 명확한 빈 공간을 가진 대표 360도 패턴
- 예측 조준 포도탄: 플레이어 현재 속도/이동 방향을 약하게 선행 예측한 5발 좁은 부채꼴
- 시간차 이중 원형탄: 느린 탄막 뒤 약 0.72초 후 다른 안전지대를 가진 빠른 탄막

Phase 2:
- 느린 원형탄 → 약 0.65초 뒤 예측 조준탄
- 돌진 예고 → 고정 방향 돌진 → 종료 위치 원형탄
- 서로 다른 안전지대를 가진 시간차 이중 원형탄

### 거대 초콜릿

Phase 1:
- 기본 조준 부채꼴
- 양옆을 조여 오는 측면 압박탄
- 첫 조준탄 뒤 시간차 재조준탄

Phase 2:
- 방향이 이동하는 3연속 스윕 부채꼴
- 측면 크로스파이어 뒤 예측 조준탄
- 서로 다른 속도의 시간차 연속 부채꼴

### 거대 양파

Phase 1:
- 빠른/느린 탄이 섞인 회전탄
- 역회전 + 안전틈 패턴
- 느린 원형탄 뒤 빠른 원형탄

Phase 2:
- 3단 탄속 회전탄
- 정회전/역회전 시간차 이중 탄막
- 첫 안전지대와 반대쪽으로 이동하는 이중 안전지대 패턴

### 돌진

TRUE BOSS 돌진 전에 약 0.56~0.64초 동안 선명한 붉은 방향 표시가 나타납니다. 예고가 끝나면 해당 방향으로 고정 돌진하므로 보고 피할 수 있지만, 돌진 종료 위치에서 작은 원형탄이 발생해 단순히 옆으로 한 번 피하는 것보다 보스의 도착 위치까지 고려해야 합니다. 2인에서는 이 예고선도 기존 네트워크 스냅샷 extras에 포함되어 게스트에게 동기화됩니다.

TRUE BOSS 처치 시 자석 1개 + 보물상자 2개 + 간식 2개를 확정 드롭하고 일반 웨이브가 재개됩니다.

## 적 탄환 가독성

v1.14에서 적 탄환을 아군 공격보다 높은 화면 깊이에 표시하고, 어두운 외곽선 + 선명한 위험색 + 밝은 중심부를 사용하도록 수정했습니다. 멍가스/영역표시/하품 등 아군 반투명 효과의 알파도 낮춰 탄막 판독성을 우선했습니다.

### 2인 부활

한 명이 HP 0이 되면 DOWN 상태로 쓰러진 위치에 남습니다.

- 살아 있는 동료가 약 84px 범위 안에 있으면 구조 진행
- 첫 구조 필요 시간 약 4.8초
- 같은 플레이어가 반복 사망할 때마다 약 +0.65초, 최대 약 6.75초
- 구조 범위를 벗어나면 진행도가 초당 45% 속도로 서서히 감소
- 부활 HP: 최대 HP의 50%
- 부활 후 약 2초 무적
- 구조 중에도 살아 있는 플레이어는 이동/공격 가능
- TRUE BOSS 중에도 부활 가능
- 둘 다 동시에 DOWN이면 GAME OVER

Host가 구조 판정을 계산하고 DOWN / 구조 진행도 / HP / 무적시간을 기존 스냅샷에 작은 상태값으로 함께 실어 게스트에 동기화합니다.
