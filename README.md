# 멍냥 서바이버즈 — Phaser 웹게임 v1.7

첨부 레퍼런스처럼 작은 대두 도트 캐릭터가 넓은 필드를 돌아다니며 몰려오는 적을 버티는 뱀서라이크 웹게임입니다.

## 캐릭터
- 찌개: 갈색 말티푸 / 앙앙 소리탄
- 만두: 하얀 말티푸 / 콧물탄
- 감자: 크림 토이푸들 / 가는 노란 오줌빔
- 구찌: 하얀 몸 + 주황 무늬 코숏 / 털뭉치

기본 수치는 동일하며 기본 투사체의 외형만 다릅니다.

## 기본 조작
- WASD / 방향키: 이동
- 기본 공격: 가장 가까운 적에게 1.5초마다 자동 발사
- ESC: 일시정지
- 카메라: 플레이어 자동 추적

## 성장
- 적 처치 → 경험치 보석 드롭
- 보석 가까이 접근 → 자석처럼 끌려옴
- 경험치가 차면 게임 일시정지 + 레벨업 선택
  - 공격력 +20%
  - 이동속도 +10%
  - 최대 HP +20 + 체력 회복

## 시간 스케일링
30초마다 새로 생성되는 적 기준:
- 최대 HP × 1.15
- 이동속도 × 1.05

누적 곱 방식입니다. 예: 60초면 두 번 강화된 수치로 스폰됩니다.

## 웨이브
- 0~1분: 좀비 2초마다 3마리
- 1~3분: 좀비 1초마다 3마리 + 박쥐 5초마다 2마리
- 3분 정각: 플레이어 주변 360도에서 좀비 50마리 포위 이벤트
- 3분 이후: 게임 지속을 위해 좀비 0.8초마다 4마리 + 박쥐 4초마다 3마리
- 매 5분: 크기 2배, 현재 시점 일반 좀비 HP의 10배인 엘리트 보스 1마리

사용자 요청에서 2~3분 구간과 3분 이후 일반 스폰 규칙은 별도 지정이 없어서, 2~3분은 2웨이브를 유지하고 3분 이후에는 강화된 3웨이브가 계속되도록 구성했습니다.

## 보스 드롭
보스 처치 시 50% 확률로:
- 자석 아이템: 주변 모든 경험치 보석을 빠르게 끌어옴
- 보물상자: 7종 스킬 중 무작위 3개 제시 → 1개 선택

## 보물상자 스킬 7종
1. 마법미사일: 5초마다 3개(레벨에 따라 증가)가 회전하며 나온 뒤 적 추적
2. 축소 광선: 기본 투사체 적중 시 적 축소 + 3초간 접촉 피해 15% 감소
3. 마도사의 주스 상자: 기본 투사체 적중 시 최대 HP의 5% 회복
4. 감시의 장막: 30초마다 다음 공격 1회를 막는 보호막 생성. 현재 v1 적은 별도 스킬이 없어 접촉 공격 1회를 막는 것으로 동작
5. 검을 뽑아라: 3초마다 플레이어 위·아래 동시 베기
6. 지옥의 전도체: 주기적으로 플레이어 둘레에 원형 불기둥
7. 탄환 세례: 4초마다 한 적에게 탄환 5발 연사

같은 스킬을 다시 얻으면 레벨이 올라가고 일부 쿨타임/발사 수/피해량이 강화됩니다.

## 실행
Windows에서는 `START_LOCAL.bat` 실행 후 브라우저에서 `http://localhost:3000` 접속.

또는:
```bash
npm start
```

## 배포
GitHub 새 저장소에 이 프로젝트를 올리고 Render에서 새 Web Service를 만드세요.
- Language: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: 비움
- Free 플랜 가능

Phaser는 CDN으로 불러오기 때문에 실제 플레이 브라우저에서 인터넷 연결이 필요합니다.


## v1.1 변경점
- 초반 경험치 요구량 대폭 완화: Lv1→2는 2XP, Lv2→3은 3XP부터 시작하며 이후 점점 느려지는 곡선
- 초반 적 체력 하향으로 기본 공격 한두 번에 처치 가능
- Lv.5, 10, 15...마다 일반 레벨업과 별도로 특별 증강 1회 선택
- 좀비/박쥐 대신 강아지·고양이에게 위험한 음식 몬스터 15종으로 교체
- 포도, 청포도, 건포도, 샤인머스캣, 초콜릿, 커피, 녹차, 양파, 마늘, 파, 부추, 껌, 사탕, 술, 견과류


## v1.2 전투 확장
- 게임 시작 시 `Paws Against The Horde → Victory Pose → Thousand Blade Ascent` 순서로 재생 후 다시 처음부터 반복됩니다.
- 기본 투사체 발사음, 적중 타격음, 적 탄환 발사음, 플레이어 피격음을 Web Audio 효과음으로 추가했습니다.
- 45초 이후부터 일반 몬스터보다 크고 흉측한 정예 위험식품이 주기적으로 등장하며 플레이어를 향해 투사체를 발사합니다.
- 5분마다 등장하는 보스는 정예보다 훨씬 크고 3연발 투사체를 사용합니다.
- 화면의 WAVE는 10초마다 1씩 증가하며, WAVE 35 / 70 / 105...에서 기존 몬스터와 적 탄환이 사라지고 TRUE BOSS 전용 탄막전이 시작됩니다.
- TRUE BOSS는 3종 외형/공격 패턴을 순환하며 원형 탄막, 조준 부채꼴 탄막, 회전 탄막과 돌진을 사용합니다.
- Lv.10, 20, 30...마다 관통탄·광역 폭발탄·거대 탄환·튕기는 탄환·본능의 충격파 중 3개가 무작위로 제시됩니다.
- 우측 하단에서 BGM/SFX 볼륨을 각각 조절할 수 있습니다.


## v1.3 밸런스/증강 개편

- 5레벨 특별 증강 약화: 사냥 본능/자석 코/튼튼한 배/우다다! 수치 축소, 쌍발 본능 제거
- 10레벨 전투 증강 전면 교체 및 레벨업 가능: 똥강아지, 원반 던지기, 댕자후, 멍가스, 음파 하품, 영역표시, 마성의 뾱뾱이 인형

## v1.8 온라인 2인 협동
- 같은 Render 링크에서 `2인 방 만들기` → 5자리 방 코드 공유 → 친구가 `방 입장`으로 접속합니다.
- 최대 2명이 같은 필드에서 실시간으로 플레이합니다. 서버는 방장이 게임 판정을 담당하고 상대 입력/상태를 동기화합니다.
- **공유:** 경험치, 레벨, 생존시간, 웨이브, 팀 처치 수. 어느 플레이어가 경험치 보석을 먹어도 팀 경험치가 올라갑니다.
- **개인:** HP, 공격력, 이동속도, 공속, 경험치 획득 보너스, Lv.5 증강, Lv.10 증강, 보물상자 스킬.
- 공유 레벨이 오르면 두 플레이어에게 각각 무작위 3개의 선택지가 별도로 뜹니다. 각자 선택을 끝내야 게임이 재개됩니다.
- 적은 살아 있는 두 플레이어 중 가까운 플레이어를 추적합니다. 한 명이 쓰러져도 다른 한 명이 계속 싸우며, 둘 다 쓰러지면 게임오버입니다.
- 보물상자는 먹은 플레이어만 개인 스킬을 선택합니다.
- ESC 일시정지는 두 플레이어에게 함께 적용됩니다.
- 2인에서는 일반몹/정예몹의 추가 2P 보정은 없고 **보스만 강화**됩니다.
  - 5분 보스: HP 약 3배 보정 + 9발 조준 부채꼴과 12발 원형 탄막을 함께 사용
  - TRUE BOSS: HP 약 4.2배 보정 + 더 빠른 돌진/탄막 주기, 360도·부채꼴·회전탄막과 두 플레이어 각각을 겨냥한 조준 탄막 추가

### 기존 Render 링크에 업데이트하는 법
이미 `Pet-survivors`가 Render에 연결되어 있다면 새 서비스를 만들 필요가 없습니다. 이 버전의 파일을 GitHub `Pet-survivors` 저장소 최상위에 덮어쓰고 Commit 하면 Render Auto-Deploy가 자동으로 같은 링크를 업데이트합니다.
