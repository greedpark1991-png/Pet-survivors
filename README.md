# 멍냥 서바이버즈 — Phaser 웹게임 v1.15

작은 도트 강아지·고양이가 반려동물에게 위험한 음식 몬스터 떼를 버티는 탑다운 서바이버 로그라이트입니다. 혼자 플레이하거나 같은 Render 링크에서 2인 온라인 협동으로 플레이할 수 있습니다.

## 캐릭터

- 찌개: 갈색 말티푸 / 앙앙 소리탄 / 고유 특성 `왕성한 성량` — 소리탄 크기·판정 +10%
- 만두: 하얀 말티푸 / 콧물탄 / 고유 특성 `튼튼한 위장` — 시작 최대 HP +8%
- 감자: 크림 토이푸들 / 오줌빔 / 고유 특성 `쪼꼬미 질주` — 시작 이동속도 +6%
- 구찌: 하양+주황 코숏 / 털뭉치 / 고유 특성 `사냥꾼의 털뭉치` — 기본 공격 피해 +5%

캐릭터 선택 화면에서 고유 특성을 바로 확인할 수 있습니다.

## 기본 조작

- WASD / 방향키: 이동
- 기본 공격: 가장 가까운 적에게 자동 발사
- ESC: 일시정지 / 현재 빌드 확인
- 카메라: 자기 플레이어 자동 추적

- 보석 수집 → 경험치 획득
- 경험치가 차면 게임 일시정지 + 강화 선택
- Lv.1: 시작 특별 증강 1회
- Lv.5 / 15 / 25 / 35...: 특별 증강
- Lv.10 / 20 / 30 / 40...: 10레벨 전투 증강
- 보물상자: 7종 스킬 중 무작위 3개 → 1개 선택

## v1.15 기본 회복 루트

레벨업에서 체력 카드만 강제로 고르는 상황을 줄이기 위해 필드 회복 루트를 추가했습니다. 기존 최대 HP 강화와 마도사의 주스 상자는 그대로 유지됩니다.

- 간식: 먹은 플레이어 최대 HP의 20% 회복, 초과 회복 없음
- 일반몹: 간식 드롭 없음
- 정예: 처치 시 10% 확률로 간식 1개
- 일반 보스: 처치 보상에 간식 1개 확정
- TRUE BOSS: 처치 시 간식 2개 확정
- 모든 레벨업: 살아 있는 플레이어 최대 HP의 3% 회복
- 2인: 간식을 실제로 먹은 플레이어만 회복, DOWN 플레이어에게는 적용되지 않음

마도사의 주스 상자는 회복 특화 빌드 역할을 유지합니다. 개이득 다발탄의 첫 적중은 정상 회복하고 같은 짧은 연속탄 묶음의 후속 적중은 감소 효율을 적용하는 v1.14 안전장치도 유지됩니다.

### v1.14 시간 스케일링

기존의 30초마다 HP ×1.15 / 속도 ×1.05 무한 곱연산을 제거했습니다.

현재 일반몹/정예의 시간 기반 배율은 완만한 곡선 + 상한 방식입니다.

- 약 5분: HP ×3.10 / 속도 ×1.14
- 약 10분: HP ×6.44 / 속도 ×1.28
- 약 15분: HP ×11.01 / 속도 ×1.42
- 20분 이후: HP 최대 ×12 / 속도 최대 ×1.42
- 접촉 피해는 0~3분은 기존값 유지, 이후 최대 ×1.40까지 완만하게 증가

후반 난이도는 HP/속도 폭증보다 적 수, 고속 적, 정예 비율, 정예 탄환, 변이, 혼합 습격, 보스 패턴으로 올립니다.

## 정예 변이

5분 이후부터 정예에게 한 가지 변이가 붙을 수 있습니다. 한 정예에게 여러 변이가 동시에 붙지는 않습니다.

- 신속: HP는 낮지만 빠르고 2연 탄환 사용
- 중장갑: 느리지만 HP/접촉 피해가 높음
- 분열: 죽을 때 약한 자식 몬스터 3마리 생성
- 지원: 주변 일반몹 이동속도를 소폭 강화하고 3발 지원 사격

변이 정예 위에 전용 이름/아이콘이 표시됩니다.

등장 횟수가 올라갈수록 다음 요소가 점진적으로 강화됩니다.

- HP
- 접촉 피해
- 이동속도 소폭
- 공격 주기
- 탄속
- 부채꼴 탄 개수
- 후반에는 작은 원형 보조 탄막

일반 보스는 여전히 TRUE BOSS보다 훨씬 약한 중간 난관 + 보상 제공 역할입니다. 처치 시 기존 자석/보물상자 50:50 보상에 간식 1개가 추가로 확정 드롭됩니다.

### v1.15 일반 보스 / TRUE BOSS 충돌 방지

TRUE BOSS 조건이 충족되어도 살아 있는 일반 보스를 즉시 삭제하지 않습니다.

- `pendingTrueBoss` 예약 상태로 전환
- 일반 보스가 살아 있으면 신규 일반몹/정예/이벤트 스폰 중지
- 약 24초 동안 현재 일반 보스를 마무리할 기회 제공
- 그 안에 처치하면 기존 보상 + 간식이 정상 드롭
- 24초를 넘기면 일반 보스를 정리하되 자석/보물상자 중 1개 + 간식 1개 보장
- 일반 보스 스폰 이후 TRUE BOSS 실제 시작까지 최소 약 60초 간격 확보
- TRUE BOSS 직후 60초 이내에 예정된 일반 보스는 해당 회차만 건너뛰어 보스 이벤트 중첩 방지
- TRUE BOSS 전장 정리 시 살아 있던 일반몹/정예의 원래 XP 총량 중 50%를 팀 XP로 지급
- 이미 필드에 떨어진 경험치 보석, 자석, 보물상자, 간식은 삭제하지 않음

따라서 TRUE BOSS 타이머 때문에 진행 중이던 일반 보스 전투와 성장 보상이 통째로 무효화되지 않습니다.

## TRUE BOSS

WAVE 35 / 70 / 105...에서 TRUE BOSS 이벤트가 예약됩니다. 일반 보스가 겹쳐 있지 않으면 기존처럼 빠르게 전환하고, 일반 보스가 살아 있으면 위의 pending 시스템으로 먼저 마무리 시간을 줍니다.

실제 TRUE BOSS 전환 시:

1. 일반 스폰 중단
2. 남은 일반몹/정예 정리 + 정리 XP 50% 지급
3. 기존 적 탄환 정리
4. 약 1.25초 경고
5. 보스 이름 표시
6. 전용 탄막전 시작

보스는 거대 포도 → 거대 초콜릿 → 거대 양파 순서로 반복되며 HP 50% 이하에서 2 PHASE에 진입합니다. v1.15에서는 단일 공격 분기 대신 패턴 메타데이터(`id / phase / weight / cooldown / minDistance / condition / execute`)를 사용하고 최근 2개 패턴을 우선 회피해 같은 공격이 연속으로 몰리는 현상을 줄였습니다.

### 거대 포도

Phase 1:
- 회전 원형탄: 이동하는 명확한 빈 공간을 가진 대표 360도 패턴
- 예측 조준 포도탄: 플레이어 현재 속도/이동 방향을 약하게 선행 예측한 5발 좁은 부채꼴
- 시간차 이중 원형탄: 느린 탄막 뒤 약 0.72초 후 다른 안전지대를 가진 빠른 탄막

Phase 2:
- 느린 원형탄 → 약 0.65초 뒤 예측 조준탄
- 돌진 예고 → 고정 방향 돌진 → 종료 위치 원형탄
- 서로 다른 안전지대를 가진 시간차 이중 원형탄

### 거대 초콜릿

Phase 1:
- 기본 조준 부채꼴
- 양옆을 조여 오는 측면 압박탄
- 첫 조준탄 뒤 시간차 재조준탄

Phase 2:
- 방향이 이동하는 3연속 스윕 부채꼴
- 측면 크로스파이어 뒤 예측 조준탄
- 서로 다른 속도의 시간차 연속 부채꼴

### 거대 양파

Phase 1:
- 빠른/느린 탄이 섞인 회전탄
- 역회전 + 안전틈 패턴
- 느린 원형탄 뒤 빠른 원형탄

Phase 2:
- 3단 탄속 회전탄
- 정회전/역회전 시간차 이중 탄막
- 첫 안전지대와 반대쪽으로 이동하는 이중 안전지대 패턴

### 돌진

TRUE BOSS 돌진 전에 약 0.56~0.64초 동안 선명한 붉은 방향 표시가 나타납니다. 예고가 끝나면 해당 방향으로 고정 돌진하므로 보고 피할 수 있지만, 돌진 종료 위치에서 작은 원형탄이 발생해 단순히 옆으로 한 번 피하는 것보다 보스의 도착 위치까지 고려해야 합니다. 2인에서는 이 예고선도 기존 네트워크 스냅샷 extras에 포함되어 게스트에게 동기화됩니다.

TRUE BOSS 처치 시 자석 1개 + 보물상자 2개 + 간식 2개를 확정 드롭하고 일반 웨이브가 재개됩니다.

## 적 탄환 가독성

v1.14에서 적 탄환을 아군 공격보다 높은 화면 깊이에 표시하고, 어두운 외곽선 + 선명한 위험색 + 밝은 중심부를 사용하도록 수정했습니다. 멍가스/영역표시/하품 등 아군 반투명 효과의 알파도 낮춰 탄막 판독성을 우선했습니다.

## 2인 온라인 협동

같은 Render 링크에서 `2인 방 만들기` → 5자리 코드 공유 → 친구가 `방 입장`으로 접속합니다.

- 최대 2명
- Host-authoritative 구조 유지
- 공용: 경험치 / 팀 레벨 / 생존시간 / 웨이브 / 팀 처치 수
- 개인: HP / 공격력 / 이동속도 / 공속 / 경험치 보너스 / 기본 강화 / 특별 증강 / 10레벨 증강 / 보물상자 스킬
- 레벨업 시 두 플레이어가 각각 다른 랜덤 선택지를 받고 둘 다 선택해야 재개
- 보물상자는 획득한 플레이어만 선택
- 적은 살아 있는 두 플레이어 중 가까운 플레이어를 추적
- 위치 보간 / 게스트 로컬 예측 / volatile WebSocket 전송 유지

### 2인 부활

한 명이 HP 0이 되면 DOWN 상태로 쓰러진 위치에 남습니다.

- 살아 있는 동료가 약 84px 범위 안에 있으면 구조 진행
- 첫 구조 필요 시간 약 4.8초
- 같은 플레이어가 반복 사망할 때마다 약 +0.65초, 최대 약 6.75초
- 구조 범위를 벗어나면 진행도가 초당 45% 속도로 서서히 감소
- 부활 HP: 최대 HP의 50%
- 부활 후 약 2초 무적
- 구조 중에도 살아 있는 플레이어는 이동/공격 가능
- TRUE BOSS 중에도 부활 가능
- 둘 다 동시에 DOWN이면 GAME OVER

Host가 구조 판정을 계산하고 DOWN / 구조 진행도 / HP / 무적시간을 기존 스냅샷에 작은 상태값으로 함께 실어 게스트에 동기화합니다.

### 2인 보스 보정

일반몹과 정예는 별도 2P HP 보정을 받지 않고 보스만 강화됩니다.

- 5분 보스: 2P HP ×3, 다수 조준탄 + 원형 보조 탄막
- TRUE BOSS: v1.14에서는 부활 시스템 도입을 고려해 기존 2P HP ×4.2에서 ×3.5로 완화하고, 난이도는 2인 조준 탄막과 페이즈 패턴으로 유지

## Render 배포

기존 `Pet-survivors` Render 서비스가 연결되어 있다면 새 서비스를 만들 필요가 없습니다.

- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: 비움

프로젝트 파일 전체를 기존 GitHub `Pet-survivors` 저장소 최상위에 덮어쓰고 Commit 하면 같은 Render 링크가 업데이트됩니다.

Phaser는 CDN에서 불러오기 때문에 브라우저 플레이에는 인터넷 연결이 필요합니다.
